# SOP Traceability Matrix

Version: v0.1.1

Release: Public

## 1. Derivation rule

The normative pattern is:

`PROVEN_RUNTIME_FACT -> SOP_RULE -> CUSTOMER_REQUIREMENT -> ACCEPTANCE_GATE`

The reference implementation demonstrates and evidences the integration method.

The resulting SOP rule is system-agnostic.

## 4. Public traceability boundary

This public matrix preserves the derivation methodology and the fact that each normative rule is backed by a sealed reference-evidence chain.

Internal phase identifiers, filesystem locations, export roots, and operational evidence-package details are intentionally omitted from the public release. Full internal provenance remains part of the private evidence package.
